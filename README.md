# Шея 5
Android-приложение для короткой спокойной зарядки шеи и плеч.

- 4 / 5 / 6 / 8 / 10 / 15 минут
- упражнения по 30 секунд
- автоматическая последовательность
- таймер и старт 3-2-1
- пауза / продолжение / стоп
- вибрация
- экран не гаснет во время тренировки
- встроенная фоновая музыка без интернета
- без регистрации, рекламы и сетевых разрешений

Сборка APK выполняется GitHub Actions после загрузки проекта.
